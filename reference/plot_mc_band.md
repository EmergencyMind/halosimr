# Monte Carlo readiness band

Median readiness with a percentile envelope across runs. When the
ensemble has a trained arm, both arms are drawn.

## Usage

``` r
plot_mc_band(mc)
```

## Arguments

- mc:

  A `halo_mc` object from
  [`hsrunmc()`](https://emergencymind.github.io/halosimr/reference/hsrunmc.md).

## Value

A ggplot object.
